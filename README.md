# UGV-HORIZON-1
Autonomous long-range tactical surveillance rover. 💰 Build Cost: ~$220. ⚙️ Features: DJI-inspired HUD web dashboard, FlySky FS-i6X manual override, 3D-printed gear torque protection, terrain-adaptive IMU throttle, dual-sonar obstacle avoidance, NEO-6M GPS waypoint navigation, and live Pi camera video streaming.
